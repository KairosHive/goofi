FIRST SESSION

Open a patch. Find its controls.

Run goofi from this checkout and load a recipe archive with the app's file browser. Play contains the control panel and main picture. Extra tabs show a shader or an analysis view. Patch shows the nodes and cables. Point to that canvas and press F to fit the graph. The archive links in this guide point to the local files; they do not replace an open app session.

cargo run -p goofi-init
cargo run -- --load node-bundles/harmonic-geometry/examples/01-breathing-lines.gfi

Start with recipe 01. auto runs a slow round trip, about 56 seconds per cycle. Turn it off to use mix. Mix 0 is source A; mix 1 is source B. Change only one control at first, then combine them. The controls are patch globals, so the same value can drive several nodes. Point to a control to see its name; touch layouts keep names visible.

These patches open no audio device and no native window. Recipe 08 ends at a stereo mix bus. Connect AudioOut when you want to listen. Python expressions are part of the default app build; use the embedded-Python test feature when testing these saved controls.
THE CENTRAL CHOICE

What should remain continuous?

Choose the transition before the rendering method. These operations can be combined, but they preserve different things.

MoveUseWhat it means
Harmonic componentsHarmonicMorphPair sorted components. Interpolate frequency ratios or log frequency, follow the shortest phase arc, and fade unmatched components.
Component richnessextension/amountKeep the base chord and grow its harmonic or subharmonic extension. Repeated frequencies are consolidated.
Mode coordinatesHarmonicModesMap two chords first, then interpolate the plate mode coordinates. Integer endpoints have fractional visual intermediates.
Field valuesGeometryBlendCrossfade scalar fields on a common physical grid, or register different domains as images. Masks become coverage.
Curve positionsGeometryBlendResample curves by arc length. Lift 2D into z=0. Optionally center and scale both endpoints.
Mesh verticesGeometryBlendInterpolate vertices only when triangle indices and counts match. Intersections remain possible.
PicturesGeometryView → CompositeUse for unrelated graphs, curve sets, and topologies. This needs no invented vertex correspondence.
Material historyHarmonicTransport → HarmonicFlowGenerate a flow from the field, then integrate an explicit GPU ink state. Freeze and reset are independent controls.

Closed rational periods, mode indices, graph membership, and rhythm lengths are discrete. Tiny tuning changes can change them sharply. A fixed-duration trace is the useful starting point for smooth frequency motion; fixed endpoint geometries are the useful starting point for structural motion.

RECIPE 01 / 7 NODES

Breathing lines

A line has a memory of its frequencies.

Start with auto on. Major and minor harmonic structures move through a fixed exposure. Turn auto off, then move mix slowly. Change phase while mix stays still: the tuning is unchanged, but the drawing turns inside itself.

slow.out → chord.mix · chord.harmonic → trace → lineStudy · chord.packed → lightTrace
mixThe shared chord moves in log frequency. An extra seventh fades into view.
phase / stretchPhase moves components around their cycles. Stretch expands or contracts every interval.
damping / yawDamping shortens the visible trail. Yaw changes only the view.
formCompare lateral, rotary, and 3D harmonographs. Compound closes over a frequency-dependent horizon and can change when its smallest component changes.
Use trace_3d, lateral, or rotary for smooth tuning motion. Keep camera autofit off when changes in amplitude should remain visible. The GPU trace reads three selected components; a fourth can affect the CPU harmonograph without appearing as a fourth GPU axis.

RECIPE 02 / 9 NODES

Plate mode walk

Walk through modes. Then release the boundary.

The two source chords stay fixed. HarmonicModes maps each to integer plate modes before the walk starts. Move mix to interpolate those mode coordinates. Move approach to change from a closed-plate picture toward open directional interference.

chordA + chordB → modeWalk → plateLight → ink · chord.packed → plateLight
mixChanges m, n, weight, and phase between two settled mode structures.
approach0 draws plate modes. 1 draws open waves from the harmonic frame.
symmetryMoves between a cosine product and an antisymmetric swapped-axis form.
lineWidthChanges the visible zero-displacement band, without changing the field.
Fractional m and n give a smooth visual path. They are not integer eigenmodes of the original plate. The plateStudy tab is the fixed CPU endpoint A, not the current fractional GPU state. Use recipe 03 for a crossfade of complete endpoint fields.

RECIPE 03 / 8 NODES

Between media

Change the medium without hiding the tuning.

A circular plate and a quasicrystal read the same harmonic frame. Their grids describe different domains. GeometryBlend uses image registration here: both pictures occupy the same normalized square, and their scalar fields crossfade.

chord → circle + openWaves → between → mediaStudy → inkUpload → ink
mixRetunes both generators together.
approach0 is the circular plate; 1 is the open quasicrystal.
periodChanges the open field wavelength.
styleRead the same field as signed displacement, magnitude, zero lines, or contours.
The circular NaN mask becomes coverage. It fades into the open square instead of making black corner artifacts. Domain mode is stricter: it requires equal grids. Image mode is an artistic field transition, not a simulation of one material becoming another.

RECIPE 04 / 8 NODES

Sand and memory

First place the grains. Then let the ink travel.

The sandStudy tab shows equilibrium density on a circular plate. A separate tracer operator turns the same field into flow. The carriedInk tab shows a GPU state that travels along that flow and responds to the curl of its own memory.

chord → plate → sand → sandStudy · plate → tracer → memory → carriedInk
affinityPositive collects sand near nodes. Negative moves powder toward antinodes.
temperatureLow values sharpen the equilibrium concentrations.
flowMix0 follows contour circulation; 1 follows the gradient.
rate / resetRate 0 freezes stored ink. Hold reset to reseed; release it to resume.
The CPU grains are a fresh equilibrium, not tracked particles. Only memory evolves over frames. The saved patch adds a small, explicit seed injection to keep texture present during a long session. Set seed/injection to 0 for an unforced experiment; diffusion then smooths the image over time.

RECIPE 05 / 7 NODES

Knot to knot

Keep the endpoints still. Move the correspondence.

Two rational harmonic knots are built at the same sample count and tube-side count. GeometryBlend moves each vertex to its partner. The triangle list stays fixed. This avoids remapping knot winding numbers on every intermediate tuning.

chordA → knotA ┐ · chordB → knotB ┴→ crossing → knotStudy
mixMoves between the two vertex sets.
radiusChanges both endpoint tube radii before the blend.
yawTurns the common camera without changing either mesh.
Equal connectivity is a data correspondence, not proof of a knot-preserving deformation. Intermediate tubes can intersect, collapse, or pass through themselves. For unrelated topologies, render two GeometryView.image outputs and crossfade their pictures with graphics:Composite.

RECIPE 06 / 7 NODES

Interval garden

One interval structure grows several gardens.

Two seven-degree tunings drive a family of interval and recursive drawings. The same scale feeds BioColors and EuclidRhythm. Change form while holding the chord still to compare how each method uses the intervals.

chord → garden → metrics + gardenStudy · chord.tuning → palette + rhythm
formChoose chord or interval graphs, tuning points, times tables, seeded IFS, subharmonic trees, recursive polygons, or pitch lattices.
colorChoose a Biotuner palette mapping: pitch position, harmonic relation, consonance, spectral mapping, or octave-doubled light.
mixChanges the degree structure shared by the picture, palette, and rhythms.
Graphs and rhythms have discrete structures. A continuously changing ratio does not make a rhythm step count continuous. Keep the tuning fixed for rhythmic performance, or use two players and crossfade their gains. IFS uses a fixed seed, so random reseeding does not hide tuning changes.

RECIPE 07 / 10 NODES

Peaks to worlds

Make a world from a measured peak structure.

A patch-local source emits a complete four-second synthetic biosignal window. HarmonicSpectrum finds harmonic peaks and their scores for source A. Tuning derives the interval scale; TuningReduction selects four degrees for source B. TuningMatrix shows the consonance matrix of the current morph, while BioColors supplies its palette. Every analysis branch feeds a visible result.

signal → spectrum → chord.A · spectrum.peaks → Tuning → TuningReduction → chord.B · chord → world + TuningMatrix + BioColors
signalShiftMoves the synthetic partials from 6/10/15 Hz to 7/11/17 Hz.
mixMoves between measured peak ratios and the reduced interval tuning derived from those peaks.
formCompares harmonic interference, quasicrystal, lattice, acoustic, Faraday, and fixed-duration 3D traces.
Replace signal.out with a real, buffered source carrying sfreq metadata. Supply at least sfreq / precision samples. peakValues is a harmonicity score, not power. Sorted-rank pairing is not peak tracking: a detected peak crossing or disappearing can change its partner. For a controlled transition, hold two measured endpoint structures and move mix between them.

RECIPE 08 / 10 NODES

A common chord

Give sound and shape the same component weights.

HarmonicVoices reads the same harmonic frame as the drawing. It retains silent slots and component fades. Eight fixed pitch and gain columns drive the native oscillator chain. The patch ends at mixdown.out so that loading it opens no audio device.

chord.harmonic → voices → pitchBus + gainBus → oscillator → amplifier → mixdown
mixRetunes the shared frame and fades the additional component.
extensionGrows harmonic multiples without replacing the base chord.
transposeMoves the synth in octaves while the geometry keeps its relative ratios.
levelSets the gain ceiling; 0 mutes sound while the picture continues.
To listen, add audio:AudioOut and connect mixdown.out to its audio input. Start with level 0, then raise it. Native Osc follows pitch continuously. TimbreControls remains the right adapter for a tuning with its own amplitude tilt; HarmonicVoices is for an already weighted frame. A VST may capture note pitch only at gate onset.

RECIPE 09 / 7 NODES

Jade resonance

A standing wave fills the window. Its surface changes under the light.

Play opens with the controls visible. Start with sand and lichen: grains collect in nodal bands while rough colonies grow over the field. Choose dunes, coral, cells, spores, pollen, or plankton for other organic readings. Jade, brushed metal, woven silk, and porous stone remain available. Organic finishes use restrained highlights and small surface features. Canvas gives the picture the whole panel.

chordA + chordB → modeWalk → plate → jade · materialMotion.out → jade.material/texture_mix
auto / mix / symmetryAuto runs the mode walk. Turn it off to set mix. Symmetry changes how swapped plate modes interfere.
textureA / textureBChoose any two of the twelve textures. Organic options include sand, dunes, lichen, coral, cells, spores, pollen, and plankton. The four mineral and fabric finishes remain available.
textureAuto / textureMixTextureAuto runs a separate slow motion. Turn it off to set textureMix from endpoint A at 0 to endpoint B at 1. The endpoint curve is smooth.
textureScale / textureDepth / densitySet texture repeats and surface height. Density changes grain and colony coverage. These leave the source field unchanged.
relief / goldSeamChange the height of the harmonic relief and the width of its metal seams.
engraving / roughness / patinaAdd contour etching, tune highlight width, and move the jade finish from bronze to green.
light / tiltMove the light or tilt the camera to inspect the surface.
This is a stateless material renderer with explicit mode and texture controls. Mirrored extension fills every edge. Both views stretch the image to the available panel. Grains, colonies, and cells are procedural field-dependent features, not tracked particles or a biological simulation. The saved patch uses 512 × 512 for both field and material. Small detail is limited by the height-map resolution.

RECIPE 10 / 8 NODES

Living ratios

One Chladni state unfolds into the next.

Each ratio replaces one voice in an anchor chord. HarmonicModes uses Biotuner chord_to_int_modes and the pairwise builder to map the complete endpoint chords. Fixed mode frequencies keep the plate still while their weights blend. The field node then applies exp(-w²/σ²) and the notebook’s D4 maximum over density. Both endpoints and the blend travel together. The default takes four seconds per transition. Texture motion starts off; nodalLines shows the same density without surface detail.

ratios.transition → modes.transition → field.modes → organism + nodalLines · ratios.tuning → chord → field.harmonics · ratios.ratio → ratioTrace
ratiosStart with 3/2, 5/4, 4/3, 7/4, 5/3, 9/8. Each pair of consecutive ratios defines a transition between plate states.
running / stepSecondsPause at the current state or set seconds per transition. The default is four seconds.
glide / directionGlide 1 moves throughout the step. Lower values add a hold before the transition. Ping-pong reverses through the same states.
auto / mixThese control texture blending only. Auto starts off; turn it on after inspecting the shape motion.
textureA / textureB / densityChoose any two of the twelve textures. Sand gives a clear view of the moving nodal bands.
grainSize / grainHeight / bandWidthSet texture repeats, surface detail height, and nodal band width.
approach / periodApproach 0 follows the smooth Chladni mode path. Approach 1 uses the gliding anchor chord for open waves; period sets their spatial scale.
The modes tab shows each source chord, integer chord, mode cap, and actual pair list. Set anchorChord to change the other voices; pairSet selects auto, all, root, or adjacent pairs. Auto uses all pairs for three voices and root pairs for larger chords. squareSymmetry selects none, d4_max (union), or d4_sum (average). Symmetry applies to density, never signed displacement. bandWidth is sigma, initially 0.05. motion=fields avoids spatial scaling; coordinates restores the optional origin-based expansion. These blends are visual transitions, not physical plate eigenmodes. The field follows the Biotuner Chladni cymatics notebook; grains remain procedural texture features. Reset and an external clock are available on RatioSequence.

NODE REFERENCE

A small set of roles.

RatioSequence
Signal · biotuner		Timed ordered ratios with pitch glides, pause, reset, and forward or ping-pong motion. Scalar ratio and target, an anchor chord, step, phase, and a text readout. Optional external clock in seconds.
HarmonicMorph
Signal · biotuner		Optional a/b, aligned amplitudes/phases, and scalar mix. Outputs a harmonic TABLE, ordinary tuning/peak arrays, and packed shader data. Use written ratio lists when a/b are not wired.
HarmonicGeometry
Signal · harmonic-geometry		One harmonic TABLE in; geometry TABLE, scalar field, and transposed trajectory out. Choose a method and bound its resolution, sample count, and recursion depth.
HarmonicModes
Signal · harmonic-geometry		Map harmonic frames to per-ratio or whole-chord pairs. Output [4,32], or [4,64] for fixed endpoint field blends. The mapping readout reports ratios and pairs; coherent transition packets are supported.
HarmonicTransport
Signal · harmonic-geometry		A scalar geometry field becomes equilibrium density, sampled particles, tracer flow, or streaming. Field grids and circular masks survive the transfer.
GeometryBlend
Signal · harmonic-geometry		Two geometry frames and optional mix. Matching scalar fields, arc-length sampled curves, or meshes with identical faces.
GeometryMetrics
Signal · harmonic-geometry		Biotuner measurements as named scalar TABLE entries and a labeled vector. Missing or undefined measurements remain NaN.
GeometryUpload
Signal · harmonic-geometry		Geometry data to validated GPU points, lines and triangles. No CPU image rendering. Maximum 4096 primitives.
GeometryRender
Graphics · harmonic-geometry		GPU renderer with a fixed view, transparent background, antialiased lines and matte or wireframe meshes. Used in the Breathing lines geometryRender tab. Fields use HarmonicInk.
GeometryView
Signal · harmonic-geometry		A transparent RGBA drawing, 960 × 660 RGB dashboard, and finite scalar/vector RGBA upload. Supports camera controls and BioColors RGB rows.
HarmonicVoices
Signal · biotuner		Fixed pitch/gain columns for up to eight native oscillator voices. Retains component weights and silent slots. Geometry keeps its relative frequencies.
HarmonicLissajous
Graphics · harmonic-geometry		GPU projection of three selected components over a fixed exposure. Sampling, phase, damping, and camera determine the trace.
HarmonicChladni
Graphics · harmonic-geometry		GPU signed displacement or nodal/antinodal density from packed modes. D4 maximum or average applies after the density transform. Approach blends plate modes toward directional waves.
HarmonicInk
Graphics · harmonic-geometry		Signed field or prepared density to nodal lines, magnitude, displacement colors, or contours. Reads BioColors.rgb directly. Retains coverage alpha.
HarmonicRelief
Graphics · harmonic-geometry		Signed field or prepared nodal density to twelve organic and material textures. Grains, cells, and colonies follow the field with restrained highlights. Morph height detail, density, color, and light response independently of ratio motion.
HarmonicFlow
Graphics · harmonic-geometry		Persistent seeded ink. Flow advection, state-derived feedback, diffusion, and optional injection. Rate 0 freezes state exactly.

The bundle README gives array shapes, metadata, geometry connectivity, and wire contracts. Nodes use the shared goofi interfaces; a patch can be edited through the UI, CLI, or MCP with the same operations.

WORKING PRACTICE

Keep the experiment readable.

Choose one row and one meaning for amplitudes.

For channel × peak arrays, select a row in HarmonicMorph. NaN padding is removed together with its amplitude and phase. Peaks are converted to ratios against the smallest valid peak. Tuning inputs already contain ratios. Written lists accept fractions such as 7/4 and decimals such as 1.41421356.

Peaks.amps uses dB power; select db_power. HarmonicSpectrum.peakValues contains harmonicity scores; use linear when you intentionally want those scores as weights. Tuning creates pairwise degrees: its output is not aligned to the original peak amplitudes. Do not connect those arrays as if they were.

Separate motion from observation.

Phase changes the source cycles. A camera rotates the view. A field style changes color. These should not be treated as the same operation. Use a fixed camera extent and fixed field range when comparing amplitude changes; automatic fitting can make a quiet frame look large again. Many Biotuner generators normalize component amplitudes: their size is relative structure, not calibrated signal power. Use a separate image opacity or audio gain to fade the whole output.

Know where continuity ends.

The morph pairs components by sorted rank. It does not track peak identity or smooth detector jitter over time. Silent components remain in the shared frame so fixed slots can fade; discrete graph and structure methods omit them. Unequal component counts can therefore change graph topology even while continuous traces fade smoothly.

The pinned pairwise and triple plate wrappers use uniform pair weights. They do not directly express peak-amplitude weighting. Use the per-ratio plate, open fields, or an explicit blend of whole fields when amplitude weighting is central to the experiment.

Use a live preview budget.

Recipes 01–08 start at 256 × 256. The organic studies in recipes 09–10 use 512 × 512 for both its source field and material. CPU fields use 96 or 128 samples per side, and mesh grids are capped at 64. Dashboard output remains 960 × 660. Set the width and height of a new graphics:SignalIn upload too; its ARRAY input does not set the output size. Increase one resolution at a time. A sample count of 512 is a useful curve starting point; a high winding count needs more.

goofi's current shared-memory publisher reserves space for its full fan-out. Large float images can therefore use much more committed memory than their visible pixel buffer. A Windows run with large GPU readbacks and several dashboards reached that limit. The saved previews use the smaller profile. A higher resolution is an explicit experiment, not a default promise.

Capture and extend.

Use goofi's recorder for geometry arrays, metrics, or final images. Keep a geometry TABLE when you need vertices, edges, faces, or a physical field grid. Record the image when you need the final appearance. A geometry frame is data, so another node can export it or use its measurements to control a new medium.

To combine these recipes, keep one HarmonicMorph as the source and connect its harmonic or packed outputs to several destinations. Keep the geometry method, mode transition, field blend, camera, and material controls independent. For a stable performance, store two endpoint tunings and automate the blend between them.

SURVEY & DECISIONS

Built from the source.

The survey uses Biotuner revision f45570e674d8193c7780891b9053a39bf6168c1e, the same revision pinned by goofi's existing Biotuner bundle. It covers the descriptor, curve, circular, fractal, 3D, eigenmode, wave, parametric, transport, morphogenetic, transition, and metric modules.

Some upstream methods run long fresh simulations inside each response. Crystallization, reaction-diffusion, and plasma equilibrium were surveyed but were not put on a real-time frame path. The new Flow shader owns its evolving state. Polygon eigenproblems, volume extraction, and the remaining extension families remain possible future additions; this bundle does not claim to wrap every upstream API.
